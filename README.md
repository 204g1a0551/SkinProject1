## 🔬 Abstract

Skin cancers and dermatological conditions affect millions globally, with malignant melanoma representing the deadliest form if not diagnosed early. Conventional clinical diagnosis relies on expert visual inspection and biopsy, which are subjective, resource-constrained, and scarce in underserved regions. 

**AI Skin** provides an end-to-end, reproducible deep learning framework leveraging **MobileNetV2** transfer learning optimized for edge devices and Apple Silicon hardware. To eliminate the "black-box" nature of neural networks in clinical environments, the system incorporates **Grad-CAM (Gradient-Weighted Class Activation Mapping)** with dynamic convolutional layer auto-discovery to highlight morphological diagnostic features in real-time. Delivered via a high-performance **FastAPI** backend and a responsive **React 19 + TypeScript** interface, AI Skin bridges deep learning with accessible clinical decision support.

---

## 🎯 Problem Statement & Objectives

### Problem Statement
1. **High Diagnostic Subjectivity**: Visual concordance among clinicians for early melanoma varies significantly.
2. **Severe Class Imbalance**: Benign lesions (such as melanocytic nevi) outnumber malignant cancers by over 10:1 in medical datasets, creating model bias.
3. **The "Black-Box" Problem**: Clinicians cannot trust predictions from deep networks without interpretable visual evidence of what features drove the classification.
4. **Computational Barriers**: Standard heavyweight models (ResNet-152, Vision Transformers) require expensive GPU servers, making edge deployment difficult.

### Key Objectives
* Develop a lightweight MobileNetV2 architecture with custom regularized classification head.
* Implement a leakage-free two-stage transfer learning pipeline (feature extraction $\to$ controlled fine-tuning).
* Mitigate severe class imbalance via balanced loss re-weighting and bounded medical augmentations.
* Integrate dynamic Grad-CAM explainability aligned directly with native photograph dimensions.
* Expose a hardened REST API and an accessible web dashboard for real-time inference on macOS Apple Silicon.

## 🔄 Preprocessing & Clinical Augmentation

### Preprocessing Pipeline
* Input image validation (format checks, corrupted raster rejection, 0-byte detection).
* Resizing to $224 \times 224$ pixels via Bilinear interpolation.
* ImageNet channel normalization: $\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$.

### Clinically Bounded Augmentation
Medical images cannot use extreme distortions that alter clinical pathology. The augmentation pipeline strictly bounds transformations:
* **Horizontal & Vertical Flips**: Preserves lesion morphology across viewing orientations ($p = 0.5$).
* **Subtle Rotation**: $\pm 30^\circ$ rotation to model random dermatoscope angles.
* **Subtle Zoom / Crop**: Scale factor bounded between $0.85$ and $1.05$.
* **Bounded Color Jitter**: Brightness/Contrast adjusted by $\pm 10\%$; Hue bounded within $\pm 0.02$ to prevent falsifying vascular erythema.

## 🧠 MobileNetV2 & Two-Stage Transfer Learning

### Model Architecture
MobileNetV2 uses **inverted residual blocks** with depthwise separable convolutions:
1. **Feature Extractor**: 19 sequential stages (`features[0..18]`), outputting a 1280-dimensional embedding.
2. **Global Average Pooling**: Compresses spatial dimensions $[B, 1280, 7, 7] \to [B, 1280]$.
3. **Custom Classification Head**:
   ```
   Dropout(p=0.3)
   Linear(in_features=1280, out_features=256)
   BatchNorm1d(256)
   ReLU(inplace=True)
   Dropout(p=0.3)
   Linear(in_features=256, out_features=7)
   ```

### Two-Stage Training Protocol
* **Stage 1 (Feature Extraction)**:
  - Feature backbone (`features[0..18]`) frozen ($2,223,872$ parameters frozen).
  - Only classification head is trained ($330,247$ trainable parameters).
  - Optimizer: Adam ($\eta = 10^{-3}$, weight decay $= 10^{-4}$).
* **Stage 2 (Fine-Tuning)**:
  - Upper residual blocks 14 to 18 unfrozen ($2,011,591$ parameters active).
  - Reduced learning rate: Adam ($\eta = 10^{-4}$ with `ReduceLROnPlateau` decay).
  - Gradient clipping (`max_norm=2.0`) to avoid catastrophic forgetting.

### Class Imbalance Mitigation
Balanced loss weights applied to Cross-Entropy Loss:
$$w_c = \frac{N_{total}}{K \cdot N_c}$$
Penalizes false negatives on minority classes (e.g. Melanoma) to ensure sensitivity.

## 🔍 Grad-CAM Explainability Methodology

### Mathematical Formulation
For target diagnostic class $c$ and activation maps $A^k$ of the final conv layer:
1. **Neuron Importance Weights**:
   $$\alpha_k^c = \frac{1}{Z} \sum_i \sum_j \frac{\partial y^c}{\partial A_{i, j}^k}$$
2. **Class Activation Map**:
   $$L_{\text{Grad-CAM}}^c = \text{ReLU}\left(\sum_k \alpha_k^c A^k\right)$$
3. **Dynamic Convolutional Discovery**: The engine programmatically inspects model modules in reverse to discover `features.18.0` without fragile hardcoding.
4. **Resolution Upscaling**: Upscales the $7 \times 7$ activation grid to the original uncropped image resolution ($W \times H$) via bilinear interpolation.
5. **Alpha Blending**:
   $$I_{\text{overlay}} = (1 - \alpha) I_{\text{original}} + \alpha I_{\text{heatmap}}$$

## ⚡ Backend Architecture & API

Built on **FastAPI** with persistent singleton warming:
* **Zero Per-Request Reloading**: The model is warmed up once during application startup.
* **Defensive Validation**:
  - Valid images $\to$ `200 OK`
  - Unsupported MIME (e.g. `.txt`, `.pdf`) $\to$ `400 Bad Request`
  - Empty (0-byte) uploads $\to$ `400 Bad Request`
  - Broken raster / corrupted streams $\to$ `400 Bad Request`
  - Oversized payloads ($> 10\text{ MB}$) $\to$ `413 Payload Too Large`
* **CORS Middleware**: Pre-configured for seamless Vite frontend communication.
* **Interactive Documentation**: Swagger UI at `/docs` and ReDoc at `/redoc`.

## ⚠️ Limitations & Future Enhancements

### Limitations
1. **Dataset Size**: The current evaluation partition reflects sample subsets; full training on all 10,015 HAM10000 images is required to maximize minority class sensitivity.
2. **Dermatoscope Variability**: Images captured with non-polarized vs polarized dermatoscopes may exhibit light reflections.
3. **Artifacts (Hair & Gel)**: Presence of thick body hair can occasionally produce false-positive saliency in Grad-CAM.

### Future Enhancements
* Automated DullRazor hair-removal filtering preprocessing.
* Multi-modal metadata integration (patient age, sex, anatomical lesion location).
* Mobile application wrapper (React Native / iOS CoreML export).
* Federated learning support for distributed hospital data collaboration.

```bash

  --manifest-dir data/processed \
```
